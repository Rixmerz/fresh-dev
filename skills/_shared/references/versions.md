# Fresh 1.x vs 2.x — one-page cheat-sheet

Source: `docs/research/fresh-1x-2x-report.md`, verified against `denoland/fresh` tag
`1.7.3` and `@fresh/core@2.3.3` (`@fresh/plugin-vite@1.1.2`, `@fresh/init@2.3.3`). Run
`fresh_project(workspace="/abs/path")` first; `version` and `flavor` say which column
applies. 2.3.x is the stable target; 1.7.x is supported legacy.

## Detection signals (report §1.4)

| Signal | 2.x | 1.x |
|---|---|---|
| `deno.json` `imports` | `"fresh": "jsr:@fresh/core@^2..."` (the official updater's own test is `imports["fresh"]` containing `@fresh/core`), `@fresh/plugin-vite`, `vite`, `npm:preact`, `npm:@preact/signals`, optional `@/` alias | `"$fresh/": "https://deno.land/x/fresh@1.x.y/"`, `preact` via esm.sh, `@preact/signals-core`, `$std/` |
| tasks | `dev: vite`, `build: vite build`, `start: deno serve -A _fresh/server.js`, `update: deno run -A -r jsr:@fresh/update .` (builder flavor: `dev.ts` tasks) | `start: deno run -A --watch=static/,routes/ dev.ts`, `build: deno run -A dev.ts build`, `preview: deno run -A main.ts`, `cli`, `manifest`, `update: https://fresh.deno.dev/update` |
| `compilerOptions` | `jsx: "precompile"`, `jsxPrecompileSkipElements`, `types: ["vite/client"]`, `lib` incl. `deno.ns` | `jsx: "react-jsx"` |
| `nodeModulesDir` | `"manual"` | `true` only with Tailwind |
| files | `main.ts` (`export const app = new App<State>()`, `app.fsRoutes()`, no `listen()` in Vite mode), `vite.config.ts`, `client.ts`, `utils.ts` (`createDefine`), `assets/` | `fresh.gen.ts`, `fresh.config.ts`, `dev.ts` (`$fresh/dev.ts`), `main.ts` (`start(manifest, config)`) |
| imports in code | `"fresh"`, `"fresh/runtime"`, `"fresh/dev"`, `"fresh/compat"` | `"$fresh/server.ts"`, `"$fresh/runtime.ts"`, `"$fresh/dev.ts"`, `"$fresh/plugins/*.ts"` |
| build output | `_fresh/server.js`, `_fresh/server/`, `_fresh/client/` | `_fresh/snapshot.json`, `_fresh/static/` |
| lint | `lint.rules.tags: ["fresh", "recommended"]` | same |

Both: `routes/`, `islands/`, `components/`, `static/`, `.vscode/settings.json` with
`deno.enable: true`, `exclude: ["**/_fresh/*"]`.

## Behaviour that differs

| Topic | 2.x | 1.x |
|---|---|---|
| route table | filesystem crawl at dev/build (fresh source: fs_crawl.ts), inserted by `app.fsRoutes()`; no manifest | `fresh.gen.ts` manifest, regenerated by `dev.ts` on every start |
| handler export | `handlers` (preferred) or `handler`; `handlers` wins | `handler` only; `handlers` throws at startup |
| handler signature | `(ctx)`; a function with two parameters is a startup error | `(req, ctx)` |
| handler → page | `page(data, {headers, status})` or `{data, headers, status}`; page typed `define.page<typeof handler>` | `ctx.render(data)`; page typed `PageProps<Data>` |
| not found | `throw new HttpError(404)` | `ctx.renderNotFound()` |
| redirect | `ctx.redirect(pathOrUrl, status = 302)`, collapses `//` | return a `Response` |
| context | `Context` (`FreshContext` deprecated alias): `config, url, req, route, params, state, data, error, info, isPartial, next(), Component, redirect(), render(vnode), text(), html(), json(), stream(), upgrade()` | `FreshContext`: `url, basePath, route, params, state, data, error, destination, isPartial, render(data), renderNotFound(), Component, next()` |
| typed state | `createDefine<State>()` in `utils.ts` + `new App<State>()` | `Handlers<Data, State>`, `MiddlewareHandler<State>`, `PageProps<Data, State>` |
| middleware file | `default` = `define.middleware(fn)` or array, or `handler`/`handlers` = fn or array; by-method object rejected | `handler` = `MiddlewareHandler` or array, `(req, ctx)` |
| global middleware | `app.use(...)` in `main.ts`, registration order | plugins in `fresh.config.ts` only |
| layout | `default` = `define.layout(...)`; a `handler` export only warns | `default` `({Component, state})` or `defineLayout`; `handler` allowed |
| error pages | `_error.tsx` (per segment), `_404.tsx` (root only, status 404 only), `_500.tsx` | `_404.tsx`, `_500.tsx`; no `_error` |
| route config | `routeOverride, csp, skipInheritedLayouts, skipAppWrapper, methods` | `routeOverride, csp, skipInheritedLayouts, skipAppWrapper` |
| per-route CSS | `export const css = ["./assets/x.css"]` | — |
| registration order | `_app` first; per segment `_middleware`(6) > `_layout`/other `_`(5) > `_error`(4) > `index`(3) > literal(2) > `(group)` > `[param]`(1) > `[...rest]`(0) | `_app` first; `_middleware`(4) > `_`(3) > literal(2) > `[`(1) > `[...`(0); same-name-different-extension → `Route conflict detected` |
| islands discovery | `islands/**` recursive, `routes/**/(_islands)/**`, plus `islandSpecifiers` (Vite) / `builder.registerIsland()`; every exported function; `default` named after the file | `islands/**` recursive, `(_islands)/`, plugin islands; every exported function; id `<file>_<export>` |
| serializable props | `null, undefined, boolean, number (NaN, ±Infinity, -0), bigint, string`, arrays, plain objects, `Uint8Array`, `URL`, `Date`, `RegExp`, `Set`, `Map`, `Temporal.*`, `Signal`, computed, JSX anywhere, circular refs | `null, boolean, number, bigint, string`, arrays, plain objects, `Uint8Array`, `Signal`; JSX only as `children`; no `Date`, `Map`, `Set`, `RegExp`, `URL` |
| never serializable | functions, class instances, `Symbol`, `WeakMap`/`WeakSet`, streams, promises | functions, class instances, and the types above |
| runtime module | `fresh/runtime`: `IS_BROWSER, asset, assetSrcSet, Head, Partial, HttpError` | `$fresh/runtime.ts`: `IS_BROWSER, asset, assetSrcSet, Head, Partial, useCSP` |
| static files | `app.use(staticFiles())` required; its position in `main.ts` decides precedence; `staticDir` may be a list (first match wins); imported CSS lives in `assets/` via `client.ts` | served automatically before routes; CSS in `static/` |
| partials | `<Partial>`, `f-client-nav`, `f-partial`, `?fresh-partial=true`, `ctx.isPartial`, plus `f-view-transition` | `<Partial>`, `f-client-nav`, `f-partial`, `ctx.isPartial` |
| built-in middleware | `staticFiles, trailingSlashes, cors, csrf, csp, ipFilter` from `"fresh"` | none; `router.trailingSlash` config; plugins |
| WebSockets | `ctx.upgrade()`, `app.ws(path, handlers)` | — |
| Tailwind | `tailwindcss` + `@tailwindcss/vite` in `imports`, `tailwindcss()` in `vite.config.ts`, CSS imported from `client.ts` | `$fresh/plugins/tailwind.ts` in `fresh.config.ts`, `tailwind.config.ts` `content`, `static/styles.css` directives, npm deps |
| type check | `deno check` (task `check` = fmt, lint, check) | `deno check **/*.ts && deno check **/*.tsx`, or `deno check main.ts` (imports the manifest) |
| update | `deno run -A -r jsr:@fresh/update .` | `deno run -A -r https://fresh.deno.dev/update .` |

## Identical in both versions

- Crawled extensions: `tsx`, `jsx`, `ts`, `js` only; files matching
  `/[._]test\.(?:[tj]sx?|[mc][tj]s)$/` skipped.
- Any `(_xxx)/` directory excluded from routes; `(_islands)/` registers islands;
  `(_components)/` is just ignored.
- `pathToPattern`: trailing `index` dropped, `[id]` → `:id`, `[...rest]` → `:rest*`,
  `[[opt]]` (whole segment) → `{/:opt}?`, `(group)/` removed, mixed literals allowed,
  `][` throws, `routeOverride` replaces the whole pattern.
- `URLPattern` matching: static beats dynamic; dynamic in registration order.
- Special names `_app`, `_layout`, `_middleware`, `_404`, `_500` (+ `_error` in 2.x).
- Only islands hydrate; `routes/` and `components/` are server-rendered; event handlers
  there never fire (`deno lint` `fresh-server-event-handlers`).
- `lint.rules.tags` `fresh` rules: `fresh-handler-export`, `fresh-server-event-handlers`,
  `jsx-button-has-type`, `jsx-no-children-prop`, `jsx-no-comment-text-nodes`,
  `jsx-no-unescaped-entities`, `jsx-no-useless-fragment`,
  `jsx-void-dom-elements-no-children`, `react-no-danger`, `react-no-danger-with-children`,
  `react-rules-of-hooks`.
